Project structure
- index.html: the complete responsive invitation website.
- assets/boy-childhood.jpg: Hady's childhood photo.
- assets/girl-childhood.jpg: Shahd's childhood photo.
- assets/proposal-scene.jpg: proposal scene image.
- netlify.toml: Netlify static publishing configuration.

Deploy with Netlify
1. Connect this GitHub repository to Netlify.
2. Choose the main branch.
3. Build command: leave empty.
4. Publish directory: .
5. Deploy. The complete repository must be published so the assets folder is included.

Do not upload index.html by itself: the images are loaded from the assets folder.
After every push to main, Netlify can automatically publish the updated site.
